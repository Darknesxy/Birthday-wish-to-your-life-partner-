## 🌌 About The Project

**Birthday Universe** is an interactive birthday website built using pure:

- 🎨 HTML
- 💅 CSS
- ⚡ JavaScript

Instead of sending a simple birthday message, this project turns the birthday wish into a small interactive journey.

The visitor moves through different sections containing memories, challenges, music, games, wishes and hidden surprises.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🎬 Loading Screen | Animated introduction before the website begins |
| 💕 Interactive Pages | Smooth navigation between different sections |
| 📸 Memories | Clickable memory gallery with animated cards |
| 💌 Love Notes | Interactive notes with reveal effects |
| 🌌 Constellation | Find all six hidden stars |
| ❤️ Heart Game | Interactive mini-game |
| 🎵 Background Music | Music throughout the experience |
| 🎶 Our Song | Special song section |
| 🎂 Birthday Cake | Animated birthday cake and candle |
| ✨ Make A Wish | Interactive birthday wish |
| 🔐 Secret Vault | Hidden surprise section |
| 💖 Animations | Glows, floating elements, transitions and effects |
| 📱 Responsive | Designed for mobile and desktop |
